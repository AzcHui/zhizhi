>
> | | 内容 | 状态 |
> |---|---|---|
> | **M4-a · 数据接线** | 浮窗自己把内核当 **sidecar** 拉起 + **长连接读它的 stdout** → 数字实时刷新；顺手读 stderr，**把只只说的话显示到窗口上**。**不需要定壳** | ✅ **已完成**（见下） |

>
> 💡 **为什么这个拆分重要**：「要不要定壳」和「能不能实时」是两件事 —— 定壳解决的是**颜值 / 托盘 / 自启 / 分发**。
> 而数据接线这条路，**换成任何外壳都一样成立**（`stdout = 一行 JSON` 是 M0 就锁死的约定），所以先做不浪费。

**✅ M4-a 已收尾（2026-10-14）** —— 「最小可用只只」跑起来了，实测证据：

| 验收点 | 实测结果 |
|---|---|
| 窗口**自己**拉起内核 | 日志：`内核已作为 sidecar 启动：PID=24716 … --interval=400 --sustain-ms=800 --cooldown-ms=2000` |
| 数字**实时刷新**（不再是打开时采一次） | 截图里状态行写着 **`已看 16 轮`**；CPU 从 **96.0%（负载中）→ 30.5%（负载结束）** —— 数字跟着真实情况在动 |
| **只只的话显示在窗口上** | 日志（浮窗侧）：`只只说了［warn］：有点烫。CPU 95.4%，要不要看看是谁在偷跑？` → 截图里那一行正是它（`100% 的 CPU，…`） |
| 渲染没坏 | `-RenderCheck`：**绘制期异常次数 0** |
| 关窗时收掉内核（不留孤儿） | 日志：`内核 sidecar 已收掉`；自检里 `内核已收掉 : True` |

> 📌 技术上踩实的一件事：**读子进程输出绝不能用 `add_OutputDataReceived`**（那回调在线程池线程上，
> PowerShell 脚本块在那儿会炸）→ 改用 **UI 线程上的「轮询异步读」**（每次挂一个 `ReadLineAsync()`）。
> 另一条：**必须显式设 UTF-8 编码**，否则只只说的中文会被按 GBK 解码成乱码。两条都写进《环境基线》了。

> ⏸️ **M4-b 搁置（2026-10-14）**：用户决定「**M4 不卡主线，先搁置**」—— 搁置的是**整容那半**。
>
> **搁置理由 + 选型讨论结论（留档，别重复讨论）**：
> ① **M4 不阻塞任何东西** —— 内核独立、`pnpm start` 现在就能用，浮窗也能看手感；
> ② **现在正是 UI 需求最不明确的时刻**（「设置在后续继续加」+ **M5–M8 会决定浮窗上显示什么**）→ **在最模糊的时刻做最贵的决定不明智**；
> ③ **「不抢焦点」在所有方案里都得自己打** —— Tauri 的窗口 API **不直接暴露 `WS_EX_NOACTIVATE`**（须引 `windows` crate 调 `SetWindowLongPtrW` 自己加）；Electron 的 `focusable:false` 底层同位，但会与拖拽/交互打架 → **M3 验证过的 Win32 技术不会浪费，换任何方案都能搬过去**；
> ④ 只只**不需要跨平台** → Electron / Tauri 只剩「颜值」一个卖点；另有一条**被漏掉的路**：**C# WinForms**（用 Windows 自带的 `csc.exe`，**零安装**、体积几十 KB、命门直通、可拆多文件）。
>
> **结论**：外壳等 **M5–M8 走完、浮窗要显示什么定下来**之后**一次做对**。
> 真要现在定路线 → 倾向 **Tauri**（M9 要开源 + 对齐主业 Vue3 + 有现成参考 BongoCat / EcoPaste），**前提是愿意装 Rust**。
