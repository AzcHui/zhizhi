## 三、⚠️ 浮窗方案自己的 3 个技术点（必须提前知道）

这几个是"类输入法候选框"真正的讲究。**不设对，会非常难受。**

### 1. `WS_EX_NOACTIVATE` —— 这是命门 ⭐

**症状**：不设它，你点一下只只的按钮，**你正在写的代码编辑器就失去焦点了**——光标不见了、输入法候选框没了、下一个字符打到了别的地方。

**这是什么**：Windows 的规则是「窗口被点击 → 它成为前台窗口 → 其他窗口失去焦点」。要违反这条规则，必须显式声明。

**正解**（这就是输入法、屏幕软键盘、剪贴板工具共用的同一套技术）：

| 扩展样式 | 作用 |
|---|---|
| **`WS_EX_NOACTIVATE`** | ⭐ **点击不激活它**（不抢键盘焦点） |
| `WS_EX_TOPMOST` | 置顶 |
| `WS_EX_TOOLWINDOW` | 不出现在任务栏、不进 Alt+Tab 列表 |
| `WS_EX_TRANSPARENT` + `WS_EX_LAYERED` | **折叠时点击穿透**（见第 2 点） |

**辅助配套**（做全了才干净）：
- 显示时用 `SW_SHOWNOACTIVATE`（不是 `SW_SHOWNORMAL`）
- 处理 `WM_MOUSEACTIVATE` 时返回 `MA_NOACTIVATE`
- WPF 里对应 `ShowActivated="False"`；Tauri 需要用 `windows` crate 调 `SetWindowLongPtrW` 自己加（**Tauri 的窗口 API 不直接暴露这个**，这是 Tauri 做浮窗的已知坑）

### 2. 折叠时点击穿透

**症状**：只只收起成一个小图标后，如果没设穿透，**那一小块屏幕就"死"了**——你点不到它底下的东西。

**正解**：折叠态加 `WS_EX_TRANSPARENT | WS_EX_LAYERED`；展开时**原子地**去掉这个标志（去早了会吞掉一次点击）。

> 这有个现成的参考实现：**Edge Drop**（Windows 剪贴板浮窗），它就是这套模式：
> **折叠时穿透 + 展开时 `WS_EX_NOACTIVATE`，两个标志解决两个不同的问题，缺一不可。**

### 3. 全屏应用时必须自动隐藏

**症状**：全屏独占模式（游戏、PPT 演示、全屏视频）下，浮窗要么看不见、要么被压住、"要么在最上层挡着你"。

**正解**：**检测到全屏窗口就自动隐藏浮窗。**

**而且这正好呼应我们定的"沉默"原则**——全屏时闭嘴，本来就是宠物的分寸感。**一举两得。**

## 四、那"摸摸"怎么办？—— 不用砍，换个位置 ⭐

这是你这个决定里唯一需要确认取舍的地方，但**损失极小、收益很大**。

| | 原来的"摸摸" | 现在的"摸摸" |
|---|---|---|
| 位置 | **屏幕任意地方**揉 | **在只只身上**揉（浮窗内） |
| 手感 | 有点魔法感（"它在任何地方都知道"） | 更合理（**在身体上摸，本来就更自然**） |
| 风险 | 需要全局钩子 ❌ | **零风险**（窗口内普通事件） |
| 判定 | 需要防误判算法 | **不需要**（窗口内操作都是明确意图） |

**结论：功能不用砍，换个位置就行，而且更像"真的在摸它"。**

而且——**浮窗就是只只的身体**。给它一个身体，比让它"寄居在系统里"更好理解、也更好交互。

## 五、一个连带推论：Toast 该降级了 ⭐

**有了浮窗之后，Toast 的地位要重新考虑。**

原方案里，所有提醒都靠 Toast 弹。现在有了常驻浮窗，我建议改成：

```
日常说话（90%）  →  从浮窗冒小气泡（弱提醒、无声、自动消失）
P0 安全告警（10%）→  才升级为 Toast（进通知中心，你不看也在）
```

**三个好处**：

1. **Toast 变稀缺 → 反而有分量**。天天弹的提醒你会免疫，"只有出大事才弹"的提醒你会真的看一眼。**通知疲劳风险大幅下降。**
2. **顺手解决了「Toast 署名」的坑** —— 之前查到：从 PowerShell 弹的 Toast **署名会显示为「Windows PowerShell」**（普通进程没有自己的身份，只能借用）。你机器有木马史，自己弹的告警却署 PowerShell 的名，你自己都会疑心。
   👉 **现在日常根本不弹 Toast，这个坑的影响面直接缩到 10%。**
3. **视觉统一**：所有"说话"都从只只身上出来，不会一会儿气泡一会儿 Toast 一会儿托盘，割裂。

> 而那个 AUMID 注册的事，仍然建议做（署名写成「只只」），但**优先级从 P2 降到 P5**。

## 七、修正后的技术路线 ⭐

有了浮窗这个决定之后，路线要调整一个关键顺序：

### ❗ 先内核，后外壳

**这是我最想让你采纳的一条工程建议。**

```
❌ 错误顺序：先做漂亮的浮窗 → 再填监控逻辑
   （结果：花一周调窗口样式，核心判断准不准还不知道）

✅ 正确顺序：
   ① 监控内核（Node）：采样 + 四道闸门 + 写日志    ← 先跑起来，控制台能看
   ② 观察一周：它判断准不准？会不会误报？烦不烦？
   ③ 浮窗外壳：确认逻辑没问题，再套界面
   ④ 台词池 + 亲密度
```

**理由**：浮窗是"脸"，逻辑是"脑"。**先养脑，再整容。** 而且①这一步你已经有 32 个现成脚本，一两天就能跑通。

### 分阶段（修订版）

| 阶段 | 内容 | 前置 | 产出 |
|---|---|---|---|
| **P0-a** | 🆕 **监控内核**（Node，纯控制台/日志）：采样 + 四道闸门 + 进程归因 | 无 | 跑一周看准不准 |
| **P0-b** | 🆕 **极简浮窗**（PowerShell + WinForms，零安装）验证手感 | 无 | 半天，验证位置/尺寸 |
| **P1** | **正式浮窗**：Tauri 2 + Vue3 + 透明/置顶/不抢焦点/托盘 | 装 Rust + MSVC | 只只的"身体" |
| **P2** | **台词池 + 分通道**（日常走气泡，P0 告警走 Toast） | P1 | 会说话 |
| **P3** | **反馈闭环**（👍👎🔇，浮窗按钮） | P2 | 学会闭嘴 |
| **P4** | **记忆 / 行为画像 / 亲密度** | P3 | 懂得越来越多 |
| **P5** | **安全哨兵** | P4 | 🎯 你最需要 |
| **P6** | 情绪状态机 + **摸摸**（在浮窗上揉）+ AUMID 注册 | P1 | 像活的 |
| **P7** | 接 Ollama（模型只做"表达"） | P6 | 会说新话 |

> ⚠️ **注意 P0-b 的价值**：用 PowerShell 做个丑但能跑的浮窗，**半天就能验证"这个位置舒服吗、会不会挡我、按钮够不够用"**。这些问题等你花一周搭好 Tauri 再发现，就浪费了。

## 八、只只的浮窗形态定义（详见下方示意图）

### 展开态（主动说话时）

```
┌──────────────────────────────────┐
│  ┌────┐  内存有点挤，Chrome        │
│  │ ◕  │  那大胃王吃了 2.1G。       │  ← 气泡区（台词）
│  └────┘  这是这个月第 7 次了。      │
│         ─────────────────────    │
│         CPU 18%  内存 87%  磁盘 43% │  ← 状态条
│         [ 赞 ] [ 踩 ] [ 静音 ] [  ▾ ]│  ← 交互按钮
└──────────────────────────────────┘
```

### 收起态（平时，薄薄一条）

```
┌──────────────┐
│ ◕ 18% · 87%  │   ← 一个小条：表情 + 最关心的两个数字
└──────────────┘
```

**设计要点**：
- **尺寸小**，可拖拽，**记住位置**；贴边吸附
- **半透明**（建议 85~90% 不透明）
- **不抢焦点**（`WS_EX_NOACTIVATE`）—— 你打字时它永远不打断你
- **折叠态点击穿透** —— 不挡路
- **全屏时自动隐藏** —— 游戏/演示时闭嘴
- **表情变化**（◕ ◡ ✕）替代复杂形象 —— 一个字符就够表达心情，也省掉整个 Live2D 的工程量

## 九、只只的语气定义（"有人味 + 会吐槽你"）

这是它性格的落地，也是整个项目最有趣的部分。**先记几条样例，作为台词池的基准：**

| 场景 | ❌ 别这么说 | ✅ 只只这么说 |
|---|---|---|
| 内存高（第一次） | 内存占用率 87% | 「内存有点挤。Chrome 那个大胃王吃了 2.1G，要我帮你数落它吗？」 |
| 内存高（**第 7 次**） | 内存占用率 87% | **「又来了。这个月第 7 次了，还是 Chrome。我都懒得说了。」** |
| C 盘紧张 | 磁盘剩余空间不足 | 「C 盘又只剩 43G 了。**你上次清完，3 天就又满了**，这次我盯着。」 |
| 你坐了 3 小时 | 建议适当休息 | 「你连着坐 3 小时了。**我不催你**，但我记着。」 |
| 凌晨还在写 | 建议早点休息 | 「1:42 了。**你自己看着办**，我不管，我就记一笔。」 |
| 你说它说错了（点了踩） | — | 「行吧，我闭嘴。」（然后这类话真的变少） |
| 你不理它很久 | — | `◡`（**不说话，表情变淡**） |
| 你摸了它 | — | 「唔…」（开心）／「让我歇会儿…」（累）|

**风格守则**：
1. **说实话，不奉承**（你讨厌被迎合，只只也一样）
2. **错了就认**（被踩 → 真的改）
3. **不催、不说教**（「我不催你，但我记着」比「请注意休息」好一百倍）
4. **偶尔无奈，但不阴阳怪气**（吐槽的底色是关心，不是抱怨）
